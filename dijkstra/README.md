# 다익스트라

하나의 시작점으로부터 다른 모든 정점까지의 최단 거리를 구하는 알고리즘

```
서울에서 부산까지 가는 방법이 여러 개 있어요.

서울 → 대전 → 부산 (비용: 3 + 5 = 8)
서울 → 대구 → 부산 (비용: 6 + 1 = 7)
서울 → 부산 직행    (비용: 10)

🤔 "가장 적은 비용으로 가려면?"
```

이게 바로 최단 경로 문제입니다.

음수의 가중치를 가지는 간선이 있으면 사용할 수가 없습니다. (이 경우에는 벨만포드 알고리즘을 사용해야 해결 할 수 있습니다)

알고리즘 순서

```
1. 시작점 거리 = 0, 나머지 = 무한대
2. 반복:
  2.1 미확정 노드 중 거리가 가장 짧은 노드 선택
  2.2 해당 노드 확정
  2.3 인접 노드들의 거리 갱신(더 짧으면 업데이트)
3. 모든 노드 확정되면 종료
```

### 최소값을 계속 갱신하는데, 나중에 더 작은 값이 나올 수 있지 않나?

1. 가중치가 전부 양수
2. 항상 최소 거리 노드를 먼저 꺼냄

위 조건들로 인하여 다른 경로로 가면 무조건 더 멀어집니다. 그래서 음수 가중치면 다익스트라를 사용할 수 없습니다.
