### 1. 시소짝궁

[시소짝궁](https://school.programmers.co.kr/learn/courses/30/lessons/152996) 문제에서 양에 관한 쌍을 구하는 문제 단순 brute force를 이용한 완전탐색 방법은 N^2 최대 50억 번의 연산이 일어날 수 있어 시간복잡도를 줄여야 한다. 문제를 보면

### 해시맵

각 무게의 등장 횟수를 해시맵에 저장하고, 순회하면서 짝궁이 될 수 있는 무게를 O(1)에 찾는다.

**정렬과 비율의 관계**

```
내림차순 정렬 시: dict에는 나보다 "큰" 무게만 존재
→ 곱하기 방향 (×4/3, ×3/2, ×2)으로 큰 짝꿍을 찾음

오름차순 정렬 시: dict에는 나보다 "작은" 무게만 존재
→ 나누기 방향 (×3/4, ×2/3, ×1/2)으로 작은 짝꿍을 찾음
```

정렬하지 않으면 양방향 모두 체크해야 하므로, 정렬 후 단방향 체크가 더 깔끔하다.

같은 무게가 n명일 때 짝꿍 쌍의 수는 ₙC₂ = n(n-1)/2이다. 이를 조합 공식 없이 순회로 계산할 수 있다.

```
예시: 같은 무게 3명 -> ₃C₂ = 3쌍

1번 처리: countMap = 0 -> answer += 0
2번 처리: countMap = 1 -> answer += 1  (1번과 짝꿍)
3번 처리: countMap = 2 -> answer += 2  (1번, 2번과 짝꿍)

총 answer = 0 + 1 + 2 = 3
```
